# 等效性说明（与成熟桌面端投标工具的差距边界）

一句话结论：**规则等效、确定性计算等效、交付版式等效；语义执行靠模型、工程化编排不等效。**

不要把"规则对齐"说成"效果一致"。下面是逐环节的真实对照，写清楚哪里能打平、哪里打不平。

## 一、逐环节对照

| 环节 | 桌面端实现 | 本技能 | 等效度 |
|---|---|---|---|
| 招标解析 | 18 项提示词；超长文件按上下文切段、分段并发、合并；整项"未提取到"自动重跑一次；并发预热公共前缀 | 同 18 项口径与提示词要求；分段与重跑由流程纪律约束 | **规则等效**，编排靠模型自查，无自动重跑 |
| 多标段 | 先识别标段、锁定投标范围，再解析 | 同（01 第五节） | 等效 |
| 目录生成 | 四阶段 + JSON Schema（ajv strict）强校验 + 节点 ID 持久化 + 仅允许程序写入 | 四阶段 + `outline_check.py` 结构校验 | **结构校验等效**，无 ajv 全量 schema、无 ID 持久化 |
| 全局事实 | `{groups:[{id,title,content}]}` + 独立"事实调整"任务 + 变更回滚 | 一张事实表（Markdown） | 结构等效，无调整/回滚链路 |
| 正文编排 | `content_plan`：写作重点、`target_words`、`table.needed`、`image_needed`、知识引用，程序按比例校正合计 | 每节先定写作重点与目标字数，`word_budget.py` 算预算 | 字数与结构等效；表格/配图/知识引用为定性要求 |
| 字数控制 | 基准换算、单节目标、落点内收 2%、单节 40%/60% 上限、<100 字不改、最多 2 轮 | 同参数，`word_budget.py` 直接给出每节目标与校正方案 | **确定性等效** |
| 正文生成 | 并发队列、逐节落盘、断点续跑、上下文压缩、图片生成与回填、一致性审计 | 分批写作、逐节保存、`bid_audit.py` 辅助 | 写作规则等效，**编排能力不等效** |
| 废标检查 | 三轮（分析→检查→定稿）+ factRegister + 纸质事项剔除 | 同三轮、同剔除口径 | 等效（模型执行） |
| 查重 | 文件指纹、元数据（RSID/OLE/PDF）、目录结构、段落、图片；权重 0.45/0.35/0.20，分档 0.75/0.55/0.35 | `bid_audit.py` 同指标同阈值 | **确定性部分等效**；不含 PDF OLE 深度取证 |
| Word 导出 | 受限 HTML → docx 转换器 + 三套系统模板 | `md2docx.py` 按「标准投标简版」参数落地 | **版式参数等效**；无受限 HTML 的图表布局语义 |

## 二、明确做不到的 6 项

1. **图片生成与回填**：桌面端可调 AI 生图 / HTML 转图 / Mermaid，并把 `asset_ref` 回填到正文。本技能只能处理已有图片文件（`![图注](path)`）。
2. **并发队列与断点续跑**：桌面端有任务队列、失败重试、暂停恢复、逐节落盘。本技能靠分批写作 + 手动续跑。
3. **上下文压缩**：桌面端在阶段切换时压缩上下文，支持几十万字整本。本技能受单次上下文限制，需按节分工。
4. **受限 HTML 版式**：三列图片、四宫格、左图右文（imageText）这类图文混排，Markdown 表达不了，导出后是单列图片。
5. **屏幕内富文本编辑**：桌面端有可视化编辑器直接改正文；本技能只改 Markdown。
6. **强 Schema 校验**：桌面端用 ajv strict 在每次写入后校验，不合规直接退回。本技能只有目录有结构校验，其余靠自检清单。

## 三、补偿手段（把不确定性压下去）

| 风险 | 补偿 |
|---|---|
| 字数跑偏 | `word_budget.py` 先算每节目标，写完再算校正方案，合计必须等于基准 |
| 目录漏评分项 | `outline_check.py` 不通过就 exit 1，不让往下走 |
| 废标漏项 | `bid_audit.py` 拿红线清单逐条找响应痕迹，再人工/模型定稿 |
| 查重误判 | 脚本只出线索，报告里明确标"命中的是线索不是结论" |
| 版式不合规 | `md2docx.py` 固定模板参数，不靠模型描述 |
| 事实编造 | 全局事实表 + 三档缺失处理 + `【待填写】` 占位 |

## 四、什么时候算"够用"

- **要交付一份能交的标书** → 够用。规则、卡口、版式都在，剩下的是模型写作质量。
- **要和桌面端逐像素一致、支持整本 30 万字一口气生成、带配图** → 不够。那需要把并发编排、图片管线、受限 HTML 渲染补上，属于再开发，不是技能能覆盖的。

## 五、版本对应

- 对标工具：成熟桌面端投标工具
- 本技能规则同步日期：2026-10-21
- 上游口径变更时优先核对三处：解析项清单、导出模板默认值、查重阈值
